# 排错

- MCP 无法启动：检查配置中 python.exe、cwd 是否指向本机仓库和 .venv；
  确认已安装依赖。日志走 stderr，不能向 stdio 的 stdout 添加普通日志。
- 显示 AutoCAD 未连接：先核对 Electrical 已启动且有图纸，Python 为 Windows 版本；
  再核对进程运行用户、权限级别和 COM 注册。不要默认把所有程序改为管理员启动。
- 检测为旧版本/普通 AutoCAD：上游版本检测尚未完成 2026 适配，先保留实际证据。
- 命令停在提示或对话框：暂停后续 MCP 写入，通过 Computer Use 查看；
  处理后回读当前文档和已产生对象，不能直接重发。
- success 但图中没变化：上游部分函数只确认提交命令，回读对象前视为未验证。
- 端子表不正确：检查真实端子连接点和原生报表；不要用线段坐标表代替接线表。
- profiles 设置未生效：当前它是规格草案；现有服务只读取根目录 config.yaml。
