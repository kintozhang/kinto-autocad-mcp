# Delta CNC / 内置 PLC / 远程 I/O 资料清单

用户拟选型号：Delta NC50E-FE（名称由用户提供；完整订货号、硬件版本、固件版本及接口能力待厂家资料核实）。本页只定义资料接收与映射要求，不声明该型号支持某种总线、地址格式或输出类型。

## 资料要求（以下表格作为核对清单）

| 资料 | 用途 | 必须明确的内容 |
| --- | --- | --- |
| CNC硬件/安装/接线手册 | 建立控制器端子与电气符号 | 完整型号、供电、连接器/针脚、公共端、屏蔽接地；厂家文档版本和页码 |
| 内置PLC编程/系统地址手册 | 将电路信号映射到程序地址 | 编程软件版本、I/O地址/变量规则、系统保留区、CNC与PLC交换区 |
| 远程I/O完整型号和模块清单 | 确定实际模块组成 | 耦合器型号、模块型号、顺序、数量、电源与端子附件；不能只写远程IO |
| 远程I/O接线/通信/映射手册 | 对齐物理端子与过程数据 | 每通道类型、公共端分组、输入输出电气类型和限制、通信协议、数据偏移及字节/位顺序 |

若已有选型表、现场模块/铭牌信息、工程配置导出、厂家示例或设备描述文件，也可一起提供。没有实机配置时先记录未知，不从相似系列手册推断。

可将原始资料保存在项目私有work/reference/delta/或其他本机资料目录后告知路径；不要提交到公开Git仓库。保留原文件和版本，不覆盖已有原始资料。当前PDF/通用MCP开发不依赖这些资料；型号专用符号与I/O映射依赖上表。

## 收到资料后的步骤

1. 建立资料索引：文件名、版本/日期、SHA256、印刷页号及PDF物理页号；区分厂家已证实与项目待确认。
2. 分开记录控制器、内置PLC接口、远程耦合器和各I/O模块；连接器针脚、模块端子、通道、程序地址、过程数据偏移分别建字段。
3. 建立原设备到目标设备的逐点映射：原功能/位号/端子/信号 → 目标型号/端子/通道/PLC地址 → 供电与信号类型 → 资料出处/核验状态。保持TREBI电位、线号和页区引用各自语义。
4. 先选一组普通输入和一组普通输出制作独立Electrical样板，验证原生符号属性、端子连接、地址显示及相关报表。未确认的参数不进入自动绘图执行配方。
5. 样板通过保存重开与报表核对后，另建国产化项目副本，逐回路替换。涉及原安全控制的功能边界单独核实，普通I/O映射不证明安全功能等效。
