# 三线传感器批量与回路模块（v5）

v5旧规格不带`execution`时仍为只读预检；新增可选字段：

```json
"execution": {
  "symbol_path": "C:/YOUR-VERIFIED-ASSET/HBB1_KINTO_R2_EC0902_TEST.dwg",
  "shared_loads": true
}
```

R2资产仍检查文件名及已验收SHA256，不接受任意同名块。限定test_only，不开放正式发布。实机验收结果见文末。

## 参数与复用范围

- 页码来自manifest的两张有效图页：第一张现场回路，第二张R2。传感器位号必须属于现场页。
- R2输入限定Port0通道0–2；其他端点虽然有厂家清单，当前布局未验收，拒绝自动绘图。
- 传感器使用已核对的VPX11IN3针号1/3/4，PNP为明确测试假设；来源信号和测试线号继续分栏。
- 连接器针号、电缆芯号与器件标识由routes提供；完整三线、配对一致性、唯一性及身份冲突检查保留。
- shared_loads=true增加按钮共享供电与指示灯共享0V。按钮返回和灯馈电连接测试边界端子，**不代表完整I545/O529控制链或实际控制逻辑通过**。

`circuit_blocks.py`供旧v4与新v5共用连接器/电缆模块；源目标引用生成和装配校验独立复用。未开放任意符号、任意布局或安全回路自动组合。修改页码/位号/受限通道不必改Python；新增器件类型仍需要验证。

## 执行与恢复

默认execute_trebi_batch沿用空白图检查、目标工程检查、修改前备份、逐步持久回执和失败停止。任何中断都不自动重放；保留失败工程，需要恢复时从备份建立新目录。

v5原生报表验收后自动关闭并重开本批次已保存图纸。每张目标均须已打开、已保存、非只读；不关闭其他图纸。独立读取元件、76个R2接点、线网、四类报表并再次验收，同时检查磁盘文件哈希未改变。重开阶段也使用同一逐步回执。

## 验收证据

分支可使同一线网包含三个端点。依据原生From/To元件句柄、针脚、实际导线句柄构建连通网络；再与设计期望对照。缺行、外来端点、错线号、跨网络句柄、重复路径均拒绝。不会把设计端点补入原生回读冒充成功。

通过的v5回执带独立重开快照，项目.p0.json绑定项目文件与回执哈希，audit_cad_project重新计算验证。未知实物型号、Revision、NC50站序/地址仍阻断正式出图；PDF仍由默认导出工具生成，并需单独全页视觉审核。

信号源/目标箭头没有针脚身份，原生From/To把它们当作透明节点，只给出一行跨页记录。`verify_signal_path`按signal_code配对箭头，要求恰好一行原生记录连接两侧真实器件针脚，线段只来自两侧箭头线网且两侧都覆盖，页码、线号、线层一致；箭头两端连线本身用原生线网回读。
