# 工具验收与映射治理计划

本轮目标：将54个旧注册工具逐项分级，默认暴露有证据的工具，修复符号列表和危险旧入口，并完成机械真实标注与电气回归。不是宣称AutoCAD全部功能或国产器件库已覆盖。

| 阶段 | 验收标准 | 状态 |
| --- | --- | --- |
| 1 工具盘点 | 每个服务端工具均有状态、范围、缺口、替代项，代码与清单自动校验 | 完成 |
| 2 默认工具集 | stdio列出的工具与默认清单完全相同，实验工具默认不可调用 | 完成 |
| 3 已知缺陷 | 本机真实符号文件查询；旧中心连线、直接移动等入口不误执行 | 完成 |
| 4 机械补齐 | 原生尺寸对象；数值回读、保存重开；明确关联性及打印边界 | 完成 |
| 5 双样板回归 | 机械样板及现有电气小项目经MCP验收；更新清单和报告 | 完成 |

后续专项：父子触点引用、PLC、端子排编辑器、国产目录及引脚映射、尺寸公差/形位公差、剖面、布局打印/PDF、3D及大项目性能。必须有对应资料与独立样板，不由本轮测试自动获得验证资格。

执行结果见[本轮报告](tool-hardening-results.md)及[逐项工具清单](tool-inventory.md)。本轮完成的是已声明的治理和样板补齐范围，37项隐藏工具并未全部完成实机验收。
